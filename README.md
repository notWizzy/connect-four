# Connect Four with Minimax and Alpha-Beta Pruning (Tkinter)

A desktop Connect Four game built with Python and Tkinter. Play against an AI that supports **Minimax** or **Alpha-Beta Pruning**, adjustable search depth, move logging, and basic threat blocking.

## Features
- **Two AI modes:** Minimax and Alpha-Beta Pruning
- **Difficulty control:** search depth slider (1 to 4)
- **Immediate threat detection:** AI blocks obvious one-move wins when possible
- **Move logs:** shows move position, AI compute time, and nodes explored
- **Game controls:** New Game, Restart, Exit

## How to Run
### Requirements
- Python 3.x

### Run
```bash
python connect_four.py
